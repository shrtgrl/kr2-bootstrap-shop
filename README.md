## Способ подключения

Bootstrap подключён локально, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Файл `css/custom.css` подключается после Bootstrap.

## Самостоятельные доработки
- Локальное подключение Bootstrap:
    Bootstrap перенесён с CDN в папку vendor/bootstrap/. Сайт не зависит от внешних серверов.

- Тема и фирменный стиль
    - Учебный шаблон «Bootstrap Shop» переработан в магазин обуви OnSight.
    - Добавлен логотип в формате SVG (images/logo.svg) во всех шапках.
    - Шаблонные «Товар 1/2/3» заменены реальными моделями с фотографиями, описаниями и ценами.

- Каталог с боковым фильтром
    - Фильтр по бренду (checkbox), типу обуви (radio), цене и размеру — статическая разметка.
    - На компьютере фильтр слева (col-lg-3) и «прилипает» при прокрутке (position: sticky).
    - На телефоне фильтр скрыт за кнопкой «Фильтры» (collapse + d-lg-none / d-lg-block).
    - Карточки выровнены по высоте: цена и кнопки прижаты к низу (d-flex flex-column + mt-auto).
    - Фото товаров одинаковых пропорций (ratio ratio-4x3 + object-fit-cover).
- Дополнительные компоненты
    - Carousel на главной странице.
    - Accordion с тремя вопросами покупателя на странице товара.
- Улучшенный сценарий заявки
    - В форме order.html добавлен выбор модели и размера, обязательные поля отмечены * и required.
    - В модальном окне каталога исправлена кнопка «Отправить»: теперь это type="submit" с атрибутом form, связанным с формой. Срабатывает проверка обязательных полей.
- Собственная палитра:
    - В `custom.css` переопределены CSS-переменные Bootstrap (`--bs-primary`, `--bs-dark-rgb`, `--bs-body-bg` и др.), поэтому цвета меняются во всех компонентах сразу.
    - Футер прижат к низу экрана (`d-flex flex-column min-vh-100` + `flex-grow-1`).

## Как проверить проект
- Открыть сайт по ссылке на GitHub Pages или файл index.html локально.
- Навигация: перейти по всем пунктам меню и выпадающему списку «Дополнительно». Пункт «Популярное» прокручивает главную к блоку #popular.
- Карусель: слайды листаются автоматически, стрелками и точками-индикаторами.
- Каталог: при ширине от 992px фильтр слева и не уходит при прокрутке. «Сбросить» очищает фильтр.
- Модальное окно: «Заказать» в любой карточке открывает окно. «Отправить» с пустыми полями показывает подсказку браузера.
- Страница товара: вопросы FAQ раскрываются, при этом открыт только один.
- Форма заявки: без имени, e-mail, модели, размера и согласия форма не отправляется. «Очистить» сбрасывает поля.
- Адаптивность: в DevTools (Toggle device toolbar) выбрать ширину телефона. Меню сворачивается в бургер, фильтр каталога открывается кнопкой «Фильтры», карточки и поля формы идут в один столбец, горизонтальной прокрутки нет.
